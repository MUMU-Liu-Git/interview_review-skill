# 实战复盘卡片 · 完整结构模板

写进 `interview-bank.json` 的 `reviews[].md` 字段（Markdown 字符串）。页面用迷你 Markdown 渲染，支持 `**加粗**`、`- 列表`、`1. 有序`、`### 标题`、`> 引用`、`---`、`` `代码` ``、`[链接](url)`。

**危险信号自动高亮**：正文里凡是 `【翻…】` 和 `【漏…】` 会被页面自动渲染成红色加粗，无需手动加样式。其余 `【亮】【稳】【改】` 保持普通加粗。

六个必备维度（用户要求）：时间、标题、高亮复盘对象、一句话总结、分维度归类与分析、三个改进点/下一面必做。有素材时补充“完整版”里的可选板块。

## 模板（整段作为 md 字符串，\n 为换行）

```
> 复盘对象：{YYYY-MM-DD} {公司} {岗位} · {轮次}（约 {时长} 分钟，{面试官身份}）。按 D1–D11 维度归类实际问到的问题。**结论：{一句话定性，含最亮点与最大短板}。**

### 一句话总览
{本场火力分布：哪些维度被追问最狠、哪些零命中；面试官在意什么；最终反馈。}

### D{n} {维度名}（{L层}）{· 可选小标注，如“本场主战场”}
- **[{时间戳}] {面试官问题原话或概括}** → {你的回答要点}。**【{flag}】**{点评：好在哪/坏在哪}。对应题库 **Q{id}**。

（按实际问到的维度重复若干个 ### 段；每题一条 - 列表项。翻车/漏答处用 **【翻…】**/**【漏…】**。）

### 出题分布（{有效问题数} 个）
- D{n} {维度名}：{题数}{· 可选注释}
- **零命中：{没问到的维度}**

### 面试官原话反馈
> {原话引用，可选}

### 三个最该改进的点（下一轮必做）
1. **{改进点标题}**：{具体怎么改，给出可执行的新话术/新结构}。
2. ...
3. ...

### 关键情报（比复盘更值钱）
- {挖到的团队/业务/选人标准/流程等真实情报，可选}

### 下一轮战术
- {针对下一轮的具体准备动作，可选}
```

## hl 高亮色规则（侧栏链接颜色，按本场整体表现）
- `green`：整体稳/亮为主，拿到正面评价或大概率过。
- `orange`：中等，有明显可改但未翻车。
- `red`：翻车或有重大失分（如被当场点破、连续卡壳）。

## 真题题干写法（questions[].text）
真题入库时，题干末尾用括号附公司来源 + 一句话点评，并带 `原题` 二字（双保险：`real:true` + 文本含“原题”）：
```
{问题}（**{公司}原题**｜{【flag】当场表现与点评}）
```
例：`竞品这么多，你做得有创意的点是什么？（**示例公司原题**｜【亮】用"识别-响应-报告"三段讲差异，面试官认可）`

## 荧光/高亮标注规则（写 md 时按语义选对标记）
页面会按下列规则自动上色，**写内容时按语义选对标记即可，不要手动写颜色**：
- **重点结论** → 用 `**…**` 加粗，渲染为**蓝色荧光笔**。
- **旗标** `【亮/稳/改/漏/翻】` 一律渲染为图例徽章；**徽章后紧跟的加粗文字一律不加荧光**（徽章颜色已表语义，纯加粗即可）。
- **危险信号（失误/翻车/卡壳/问错等）**只用两种方式上色：
  - `【漏】`/`【翻】` 的点评整条会成为玫红高亮块（块内玫红字、不叠荧光）。
  - 没有旗标的行内危险短语（如"连续卡壳两次""主动换问法救场"）用 `!!…!!` 包起来 → 玫红荧光。
- **优先级：危险 > 重点**。`【漏】`/`【翻】` 的点评整条会成为玫红高亮块；块内一律玫红字体，**不要再在块内叠加 `**` 或 `!!`**（同色系原则：黄块内橙、紫块内紫、玫红块内玫红字）。
- 所有徽章（旗标/难度/真题）与题号按钮都是纯色，不要期望它们有荧光。

## 一句话总览的格式规范（强制）
「### 一句话总览」里的**分维度统计**，各项之间一律用全角竖线 `｜` 分隔（页面把 `｜` 渲染成加粗分隔符），不要用逗号/顿号。普通统计项不加 `**`；但其中「高频/最重」那一项与「重点结论」要用 `**…**`（加粗 + 蓝色荧光笔）。统计串末尾用 `｜——` 接转折/结论散句。示例：
```
本场 10 个问题里｜**D10 动机与职业规划占 4 题（最重）**｜D1 项目与权责 3 题｜D11 个人特质 2 题｜技术深水区（D3/D4）｜数据口径（D2）一道没问｜——**HR 面测的是动机稳定性……**技术追问留给二面。面试官原话："……"
```

## 可选的四色荧光笔标记（页面工具栏也会插入这套语法）
正文里需要手动上色时用：`==b|文本==`=蓝、`==o|文本==`=橙、`==p|文本==`=紫、`==r|文本==`=玫红。页面顶栏的「加粗 / 荧光笔」工具栏在答题框里选中文本后，就是插入 `**…**` 与 `==色|…==` 这两套标记。
